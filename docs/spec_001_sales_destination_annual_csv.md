# SPEC 001 Sales Destination Annual CSV

## Goal

統計データ画面を起点に、販売先 x 取扱個所単位の年間実績を追加集計なしで参照できる状態を作る。

初回機能は、ブラウザ内の表よりも先に、年間集計済み CSV を安定して出せることを優先する。

## Background

- 現行の統計データ画面には、販売先単位、取扱個所まで集計単位に含める、CSV 出力が既にある
- `Gscsc4010CsvOutAction.do` は、3 か月以内の条件では CSV 添付で成功する
- 同じ Action は、3 か月超の条件では HTML を返し、`MGSC0095` で集計期間・比較期間とも 3 か月以内制限を返す
- したがって、年間一括取得は backend への単発 POST では実現できない

## Confirmed Facts

### Source Screen

- 対象画面: `https://www.tl-gt.net/accomodation/Gscsc4010BackTo4000Action.do`
- 送信先:
  - 画面出力: `Gscsc4010InitAction.do`
  - CSV 出力: `Gscsc4010CsvOutAction.do`

### Successful CSV Response

- Response header は `content-disposition: attachment`
- Response header は `content-type: application/octet-stream;charset=UTF-8`
- ダウンロードされた CSV の先頭 2 行は、抽出条件 1 行 + ヘッダー 1 行

### Confirmed CSV Columns

- キー列: `販売先名`, `取扱個所名`
- 現在期間と比較期間の対になる列:
  - `実績件数`
  - `CXL件数`
  - `催行率`
  - `仮予約時点室数`
  - `目減り室数`
  - `Wash率`
  - `実績室数`
  - `延人数`
  - `室料金合計`
  - `宿泊料金合計`
  - `総合計料金`

### Derived Formulas Seen In Source CSV

- `催行率 = 実績件数 / (実績件数 + CXL件数)`
- `Wash率 = 目減り室数 / 仮予約時点室数`
- 負の `目減り室数` があり得るため、`Wash率` も負値になり得る

## Product Decision

初回機能は、統計データ画面の既存条件を利用して 3 か月以内の CSV を順次取得し、userscript 側で年間集計した CSV を出力する。

ブラウザ内の年間集計テーブルは、初回機能の out of scope とする。

## In Scope

- 統計データ画面に、年間集計実行用の userscript UI を追加する
- 現在画面で利用者が選んだ条件を読み取る
- 集計期間と比較期間を 3 か月以内のチャンクへ分割する
- 各チャンクで既存の `Gscsc4010CsvOutAction.do` を利用する
- ダウンロード済み CSV を userscript 内で読み込み、年間値へ集約する
- `販売先名` と `取扱個所名` を集約キーにする
- 数量・金額列は合算する
- `催行率` と `Wash率` は合算値から再計算する
- 実績 0 行を除外した統合 CSV を出力する
- 実行中の進捗と失敗チャンクを画面に表示する

## Out of Scope

- backend に新しい年間 API を追加すること
- 既存の「画面に出力する」「CSV に出力する」ボタンの挙動変更
- 団体案件一覧ベースでの再集計
- 初回機能でのブラウザ内年間一覧テーブル表示
- 既存 CSV の列定義そのものを変更すること

## Aggregation Rules

### Chunking

- 1 チャンクは 3 か月以内とする
- 1 年分は既定で 4 チャンクに分ける
- 比較期間も同じ境界で 4 チャンクへ分割する

### Grouping Key

- `販売先名`
- `取扱個所名`

### Summed Columns

- `実績件数`
- `実績件数（比較期間）`
- `CXL件数`
- `CXL件数（比較期間）`
- `仮予約時点室数`
- `仮予約時点室数（比較期間）`
- `目減り室数`
- `目減り室数（比較期間）`
- `実績室数`
- `実績室数（比較期間）`
- `延人数`
- `延人数（比較期間）`
- `室料金合計`
- `室料金合計（比較期間）`
- `宿泊料金合計`
- `宿泊料金合計（比較期間）`
- `総合計料金`
- `総合計料金（比較期間）`

### Recalculated Columns

- `催行率 = 実績件数 / (実績件数 + CXL件数)`
- `催行率（比較期間） = 実績件数（比較期間） / (実績件数（比較期間） + CXL件数（比較期間）)`
- `Wash率 = 目減り室数 / 仮予約時点室数`
- `Wash率（比較期間） = 目減り室数（比較期間） / 仮予約時点室数（比較期間）`
- 分母が 0 の場合は `0%` とする
- 表示は既存 CSV と同様に `%` 付きの整数丸めを基本とする

### Zero Result Filter

- 既定では、次をすべて満たす行を除外する
  - `実績件数 = 0`
  - `実績室数 = 0`
  - `延人数 = 0`
  - `総合計料金 = 0`
- 将来拡張で raw 行を見たいケースに備え、userscript UI には `実績 0 行も含める` の余地を残す

## UI Requirements

- 配置場所は、統計データ画面の既存出力ボタン付近を第一候補にする
- 最小 UI は次を含む
  - 対象年
  - 実行ボタン
  - 実行状況表示
  - エラー表示
- 実行中は重複起動を防ぐ
- 失敗時は、どのチャンクで失敗したかを表示する

## Acceptance Criteria

1. 利用者が統計データ画面で販売先条件を選び、年間集計実行を押せる
2. userscript が 3 か月以内のチャンクに分割して既存 CSV 出力を順次実行できる
3. 4 チャンク分の CSV を `販売先名 x 取扱個所名` で年間集計できる
4. `催行率` と `Wash率` が合算後に再計算される
5. 既定では実績 0 行が統合 CSV から除外される
6. 既存の通常 CSV 出力ボタンの挙動は変わらない

## Verification

1. 3 か月以内条件の既存 CSV 出力が従来どおり成功する
2. 3 か月超条件の既存 CSV 出力が `MGSC0095` を返すことを再確認できる
3. userscript の年間集計で 1 年分の統合 CSV がダウンロードできる
4. 任意の 1 販売先について、四半期 CSV の合計と統合 CSV の値が一致する
5. 実績 0 行が既定で除外される
